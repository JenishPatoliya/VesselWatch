# ⚓ VesselWatch — Maritime Anomaly Detection

## Live Dashboard
[Open VesselWatch](YOUR_URL_HERE)

## What It Does
Detects suspicious ship behavior using ML by 
analyzing real AIS vessel tracking data.

## Results
- 16,937 vessels analyzed
- 681 suspicious vessels flagged  
- High risk vessels show 59hr avg AIS gap
- High risk vessels jump 1,315km after gap

## Tech Stack
Python | Pandas | Scikit-learn | TensorFlow 
SHAP | Folium | Streamlit

## Models Used
- Isolation Forest
- DBSCAN Clustering  
- LSTM Autoencoder
